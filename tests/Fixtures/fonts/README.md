# Portable test fonts

Original Noto Sans Regular and Noto Sans Arabic Regular from
[`notofonts/noto-fonts@ffebf8c`](https://github.com/notofonts/noto-fonts/tree/ffebf8c1ee449e544955a7e813c54f9b73848eac/hinted/ttf).
OFL-1.1; see the unmodified `LICENSE`. Exact paths/hashes are in `.config/dependencies.json`.

Test-only fixtures for font-directory width, Arabic RTL and concurrent shaping. Copied to test
outputs with their license, checked by `PortableTestFonts`; never downloaded during tests or
included in AGD tool packages. Runtime defaults remain the bundled Inter fonts.
