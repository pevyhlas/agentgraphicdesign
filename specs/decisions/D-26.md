# D-26 Review sheets, static gallery and legibility analysis

**Decided by**: architecture review (capability design closure, all four lenses, change 007, with
the slice refinements approved in the change 012 design closure); the static gallery without a
server was the lead's choice for this target · **Date**: capability design, pre-public history ·
**Cited by**: R-02, Q-01, Q-03, D-24, change 012

Status: accepted; built by change 012 (slice S05: S05a then S05b). The static gallery is a
directory a command rewrites and a browser opened on `file://` reloads: no server, listener or
file watching.

## Decision

### References and boundaries

- A reference is a vector document or `document#node` (a closed union with one `document` arm;
  S08 adds a family plus variant arm, D-23). A native pixel asset (`asset.agd-pixels.json`,
  its directory, or a file whose `schema` is `agd.native-pixels`) is refused before rendering with
  `REFERENCE_KIND_UNSUPPORTED` (checked lexically first, then by directory inspection, then by
  content); a later `pixels` arm is additive.
- CLI grammar: an argument whose last `#` is followed by exactly a canonical GUID is `path#node`;
  otherwise the whole argument is a path. MCP references are closed objects
  `{document, nodeId?, label?}`, confined, then inspected, then read once within 16 MiB.
- Node references use sub-node ink cropping (D-10) and keep tokens; whole documents use the
  canvas.
- Layers: Core owns specs, the builder, resolution, layout math, analysis and gallery generation
  (`GalleryWriter`, called by both surfaces); Skia owns rasterisation, composition and labels; the
  CLI owns files; MCP owns confined references, inline images and JSON.
- **Inspection before opening**: where file inspection is admitted for the asset pipeline (D-28),
  every reference file, every font directory and every immediate font-directory entry is
  inspected before it is opened; links, FIFOs, devices and other non-regular files refuse with
  `PATH_ESCAPE`. Where it is not admitted, sheets and analysis keep today's read paths as a
  **tracked deviation** (the lead's confirmed choice, removed when change 008 admits inspection),
  a linked font entry is still skipped and never opened, and `gallery write` refuses with
  `ASSET_PLATFORM_UNSUPPORTED`. One platform gate decides this, never an OS-name check.
- **Fonts per call**: one inspected font set (directories plus `Load` or `Skip` entries built by
  one shared rule routine, today's directory rules in today's order) is loaded exactly once per
  `contact-sheet`, `analyze` or `gallery write` call through a render session
  (`IRenderer.OpenSession`), and every render of the call reuses it. ≤ 16 directories, ≤ 256
  entries each, counted font files ≤ 8 MiB (larger ones skipped unopened).
- **Aggregate bound**: distinct documents plus counted font files ≤ 64 MiB per call, one builder
  copy per distinct `(reference, crop)` with masks applied on it, at most one copy live.
- **Paths in outputs**: every new JSON output and generated file writes a path as relative POSIX
  to the base directory (the CLI or MCP working directory, an explicit input) or `null`, never an
  absolute path; `documentSha256` is the SHA-256 of the exact bytes read once and parsed.
- **Colour inputs** (condition grounds, matrix sheet background, analysis grounds) are parsed once
  in CSS order, decided opaque on the alpha byte and normalised to lowercase `#rrggbb`; only the
  normalised value reaches renders and outputs. Document colours are rendered as authored.

### Raw pixels

An additive internal `RenderFormat.Rgba8`: unpremultiplied sRGB, row-major, top-down, no padding,
read back through Skia's unpremultiply (authoritative), never encoded to a file (every encode path
throws for it, and format-string maps name formats explicitly). Core `RgbaImage` validates length
and dimensions (1–8192 per side, ≤ 64 Mpx). The unpremultiply rule is characterized exhaustively
over all 32 896 premultiplied pairs and recorded.

### Contact-sheet matrix

- Rows are references and columns conditions (`--transpose` swaps them). A condition sets `size`
  (`native`, `fit` or 1–4096 px on the larger edge), `background` (an opaque colour, `checker`, or
  null for the document's own; null on a node reference means none), integer `zoom` 1–16 with
  **nearest** sampling, and a label. Shorthand `--sizes`, `--backgrounds`, `--zoom` expand sizes
  outer, backgrounds inner; an explicit `--condition` list is exclusive with them.
- Each tile is rendered directly at its size through the renderer as `Rgba8`, with the layout box
  computed from the renderer's own rounding (a mismatch is `RENDER_FAILED`, never a silent draw);
  zoomed tiles are exact block replication. A side rounding to 0 or a scale above 1000 refuses
  with `INVALID_DIMENSIONS`. The matrix sheet background must be opaque (`INVALID_PROPERTY`).
  Checker squares are `4·zoom` px, `#ffffff` then `#d4d4d8`, anchored at the cell.
- Labels in bundled Inter only; control, bidi-format and lone-surrogate characters are removed or
  replaced; explicit labels over 256 characters refuse; derived labels are trimmed.
- The result returns a cell map (references, conditions, rows, columns, cell and image boxes,
  rendered size and zoom).
- Without conditions the existing grid keeps its meaning, its 256-reference cap and its bytes
  (legacy tile recipe: render as PNG, decode, linear draw into the fitted box), narrowed only where
  a security bound needs it (inspection refusals, the 64 MiB aggregate, > 256 font entries), as a
  declared changelog item. The MCP tool cuts over from `paths` to structured `refs`; inline sheets
  stay ≤ 2048 px per side (larger ones through the gallery).
- Limits: ≤ 64 references with conditions (256 without), ≤ 32 conditions, ≤ 256 cells, ≤ 8192 px
  per side, ≤ 64 Mpx (`64_000_000`).

### Legibility analysis (Core, over `RgbaImage`)

- Request: one reference; 1–8 sizes ≤ 1024 px; 1–4 opaque grounds (default `#ffffff,#000000`;
  `checker` refused); regions `auto` (the visible direct children of the reference root) or ≤ 32
  disjoint explicit ids; a reference size (default 512, 64–1024, ≥ every size); thresholds
  `--min-contrast` (default 3), optional `--min-pair-contrast`, `--min-stroke` and `--min-gap`
  (default 1 px, ≤ 16); opt-in `--safe-zone` (square canvases only); no system fonts unless
  `--system-fonts`.
- Regions are rendered alone once per size; backgrounds are composited arithmetically. Ownership:
  the last-painted region (document pre-order by ordinal `order`) whose region-alone α ≥ 128,
  else the last-painted with α > 0.

| Metric | Definition |
|--------|------------|
| Coverage | `Σ α/255` over owned pixels, and that over the cell area |
| Region colour | over the region's **exclusive** core pixels (owned, α ≥ ⌈0.75·max⌉, no other region or content there) composited at their plateau alpha, so anti-aliasing moves it at most ±1 per channel and a translucent region keeps its opacity (`colourBasis: "exclusive"`); with no exclusive pixels, over its core pixels at the maximum artwork α (`"overlap"`), whose ground ratio is reported but not checked (`groundChecked: false`; its check is pair contrast) |
| Contrast | WCAG through a 256-entry literal sRGB-to-linear table (no `Math.Pow`); ground ratio per region, pair ratio for 4-adjacent regions (a finding only with `--min-pair-contrast`) |
| Topology | at output pixels, α ≥ 128: 8-connected components and 4-connected holes; correspondence with the reference size by exact fractional-box area averaging in integer canvas coordinates, so lost and merged are distinct |
| Stroke width | at supersample `k` (4 to 256 px, 2 to 512 px, else 1, lowered to fit the pixel budget, never below 1) on a 2× cell lattice: local thickness from one exact squared EDT, reported as the 5th percentile (nearest rank), clamped at `max(4, 2·minStroke)`; accuracy ±1/k px |
| Gap | one labelled exact EDT over the same lattice; adjacent label pairs only; a gap of g px measures g |

- Findings (warnings): `LEGIBILITY_LOW_CONTRAST`, `ASSET_SAFE_ZONE` (artwork alone, background
  excluded, α ≥ 128 outside the 0.4·W circle; shared with D-24), `LEGIBILITY_FEATURE_LOST`,
  `LEGIBILITY_GAP_CLOSED` (merged or filled), `LEGIBILITY_THIN_STROKE`, `LEGIBILITY_NARROW_GAP`.
- Outcome `failed` if any finding, else `incomplete`, else `unsupported`, else `passed`. Advisory
  unless `--fail-on` (exit 5, also for `incomplete` or `unsupported`).
- Report `agd-legibility/1` with an ordinal-sorted `checks` list; identity is `(algorithm,
  checks)` (S05a performs contrast, coverage and the optional safe zone; S05b adds topology and
  widths). Numbers carry fixed decimals; thresholds compare unrounded values; values round half
  away from zero. Analysis numbers are per platform (they come from rasters).
- Budgets: ≤ 64 Mpx per call including supersamples (over it at `k = 1` is `RESOURCE_LIMIT` for a
  standalone call); ≤ 2^32 counted operations per call in a documented step order (per size,
  per region correspondence then thickness, then gaps); when reached, the current and later steps
  are `incomplete` with no partial numbers and the report's `steps` list shows the cut; budget
  injection is a Core test seam only. Inside a gallery one shared budget is planned per reference
  against the remainder, later references become `incomplete`, and the gallery still exits 0.

| CLI | MCP |
|-----|-----|
| `contact-sheet <REFS…> -o sheet.png [--sizes] [--backgrounds] [--zoom] [--condition]… [--label]… [--transpose]` | `render_contact_sheet` |
| `analyze <REF> [--sizes] [--backgrounds] [--regions] [--reference-size] [--min-contrast] [--min-pair-contrast] [--min-stroke] [--min-gap] [--safe-zone] [--fail-on]` | `analyze_legibility` (read-only) |
| `gallery write <REFS…> -o <DIR> [sheet options] [--refs-per-sheet N] [--title] [--analyze] [--refresh N]` | `write_gallery` (confined; destructive) |

`get_capabilities` reports `analysis {algorithm, checks}`.

### Gallery: owned names and index

- Closed, flat names: `index.html`, `gallery.json`, `sheet-NNN.png` (001–016),
  `analysis-NNN.json` (001–064, the 1-based reference index), the lock `.agd-gallery.lock` (never
  listed or hashed), temporaries `.agd-gallery-tmp-<32 hex>`; the platform litter `.DS_Store` is
  ignored. Anything else refuses the write (`GALLERY_DIR_NOT_OWNED`, `details.reason` and the
  entry's basename only); enumeration stops at entry 129 (`too-many-entries`).
- `gallery.json` (`agd-gallery/1`) is untrusted input, parsed strictly: ≤ 1 MiB, depth ≤ 8,
  unknown or duplicate fields rejected, names checked against the grammar, `sha256` 64 lowercase
  hex, `bytes` a non-negative integer ≤ 64 MiB, `refs[].document` relative POSIX or null; every
  parser exception maps to `GALLERY_INDEX_INVALID` without a trace or host path. It records the
  generator, the effective font policy, the expanded sheet conditions and options, the analysis
  parameters, references with `documentSha256`, sheets, analyses and the owned files with their
  hashes. A newer AGD's fields make an older AGD refuse by design; the recovery is to delete and
  regenerate the directory.
- Without conditions a gallery uses one `native` condition with a null ground; the legacy grid is
  never used for a gallery.

### Gallery write algorithm (Core `GalleryWriter`, both surfaces)

1. Validate arguments; resolve and inspect every reference and font directory; apply the
   aggregate input bound; the output directory must not equal, contain or lie inside any input
   (`PATH_ESCAPE`).
2. Side-effect-free pre-check of the directory (classification, strict index, owned-file
   verification), so a foreign entry refuses before rendering.
3. Render everything in memory through one render session: every sheet layout and the ≤ 64 Mpx
   sheet total are computed before any render; at most 64 references per call and 16 sheets
   (`--refs-per-sheet` splits references in order); output ≤ 64 MiB. Gallery analysis always uses
   automatic regions and never gates (`--regions` and `--fail-on` refuse). The session is disposed
   before the lock wait.
4. Create only the leaf directory when its parent exists and passes inspection (no `mkdir -p`).
   Inspect the lock path: a link, FIFO, directory or other non-regular entry refuses with
   `GALLERY_DIR_NOT_OWNED` (`not-regular`); the lock is never a deletion candidate, even when
   stale. Open the lock with the document store's exclusive pattern, waiting up to 30 s
   (injectable for tests), else `GALLERY_LOCKED` with nothing changed; the OS releases it when a
   process dies.
5. Verify under the lock (authoritative): every owned file present must be listed, regular, of the
   listed length and hash (`hash-mismatch`, `size-mismatch`, `not-regular`,
   `unlisted-owned-file`); a listed file that is missing is accepted and regenerated; owned files
   over 128 MiB in one verification pass refuse with `RESOURCE_LIMIT`.
6. Delete grammar-matching, regular crash temporaries (safe: no live writer holds the lock).
7. Write a `writing` index (each file's new hash and the previous hash observed on disk, stale
   entries marked), then each new or changed file, then delete stale files (re-checking regular
   and hash immediately before each unlink), then the `complete` index. A run that finds a
   `writing` index accepts either hash, so any interrupted run, interrupted again at any step,
   completes on the next clean run without manual cleanup.
8. Every write creates a temporary sibling exclusively without following links, then renames it
   over the owned name; no existing file is written in place, so a hard link elsewhere keeps its
   bytes. Link-count probing waits for a platform probe; these rules carry the guarantee meanwhile.

Guarantee: only owned-grammar, listed, hash-matching, regular direct children are ever replaced or
deleted, and nothing outside the directory changes. A matching hash is not provenance. The
inspection before an open is not a TOCTOU control (trusted, quiescent local filesystem); with file
locking disabled two writers can leave mismatched files, which the next run refuses rather than
deletes. A checkout with `core.autocrlf` makes the next write refuse with `hash-mismatch` (delete
the directory, or mark it `-text`).

### Gallery `index.html`

UTF-8 without BOM, LF, no timestamps, fixed order, double-quoted attributes, no scripts and no
external URL. The CSP is `default-src 'none'; img-src 'self' file:; style-src 'unsafe-inline';
base-uri 'none'; form-action 'none'`, verified by recorded browser evidence (Safari and Chrome on
macOS 26, Chromium and Firefox on Linux); a blocked image adjusts the directive, never drops the
CSP. `--refresh N` (1–3600) adds `<meta http-equiv="refresh">` without `url=`. Text and attribute
contexts escape `& < > " '`; labels are wrapped in `<bdi>`; images and links name only owned
siblings. Without `--analyze`, `index.html` is byte-identical across platforms.

### Gallery exit codes

`gallery write` exits 0 when written (also with failed or incomplete analyses, recorded in the
files), 4 for bad arguments, 1 for `GALLERY_DIR_NOT_OWNED`, `GALLERY_LOCKED`,
`GALLERY_INDEX_INVALID`, `ASSET_PLATFORM_UNSUPPORTED` and other typed errors (D-27).

## Alternatives

- **More flags on the current grid**: cannot express size × background × variant.
- **Decoding PNGs with the managed decoder**: couples analysis to the artifact decoder profile.
- **Vector-only gap measurement**: does not measure what anti-aliased 16 px output shows.
- **A medial-ridge minimum or the binarized output mask for widths**: corners drive it to 0, or
  1 px and 2 px strokes look alike and thin-stroke findings can never fire.
- **Exact per-pair gaps and full disk painting**: 10⁹ to 10¹² cell visits per call under the
  limits; replaced by one labelled EDT, a clamped thickness and a counted budget.
- **A loopback preview server** (`HttpListener` or Kestrel): a new listener, Unix port and timeout
  gaps, or the ASP.NET Core runtime for the whole CLI; deferred to its own slice with a security
  review and an owner decision. Its gate inherits a host allowlist, opaque routing, a
  constant-time token check, CSP, `nosniff` and `no-store` headers, connection and timeout limits.
- **Admitting native pixel stills now**: a second domain inside one slice without its own review.
- **Composite each pixel at its own alpha**: reintroduces anti-aliasing phase dependence.

## Revisit when

Live reload becomes a real need (the deferred server slice); pixel-diff images or perceptual
metrics are needed; a pixel reference arm is designed (change 014).
