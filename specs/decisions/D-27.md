# D-27 Cross-cutting rules for the capability design

**Decided by**: architecture review (capability design closure, all four lenses, change 007) ·
**Date**: capability design, pre-public history · **Cited by**: C-09, Q-01, Q-02, Q-03, D-21 to
D-26, changes 011, 012 and 013

Status: accepted. Binds every slice that implements D-21 to D-26 (S04 to S09 of change 013); each
slice cites these rules instead of reopening them.

## Decision

### Format versioning

| Artifact | Version | Rule |
|----------|---------|------|
| Document `.agd.json` | 1 | additive optional `path.derivation` (D-22) and `group.placement` (D-23); baked geometry renders in 0.3.0 readers, which preserve the fields; declared in schema, `docs/format.md` and changelog |
| Anything that changes what an old reader renders | 2 | needs format 2 and an architecture review (C-09) |
| Asset manifest | 2 | new spellings only; v2 constructs under `version: 1` fail (D-24) |
| Family and axes files | 1 | `schemas/agd-family.schema.json` (D-23) |
| Kit descriptor, gallery index | `agd-kit/1`, `agd-gallery/1` | generated; the gallery index is parsed strictly when read back |
| Identifiers | `agd-geometry/1`, `agd-operands/1`, `agd-placement/1`, `agd-legibility/1` | a byte-moving change bumps the identifier |

New formats write keys in declaration order, reject unknown and duplicate properties, sort
unordered arrays ordinally, carry no timestamps, state explicit byte and depth limits and hold
only root-relative POSIX paths.

### File-reference rule

Every file reference in a new format (`axesFrom`, family `source`, `placement.family`, manifest
sources and later references) uses the `AssetPaths.Resolve` grammar (relative, `/`-separated, no
`..`, not rooted), is confined to the declaring file's directory (plus MCP confinement), is
inspected before opening and read with a bound, and is never dereferenced by the pure validator.
Upward references and a project-root marker are deferred.

### Diagnostic severity

The pure validator keeps errors and warnings only (`DERIV001` to `DERIV005`, `DERIV007`,
`DERIV008`). Context checks (`derive check`, `family check`, placements, analysis, pipeline and
kits) carry `info|warning|error`. Strict pipelines fail on error and warning, never on info. No
info level is added to the validation result.

### Determinism across platforms (Q-01)

| Byte-identical across platforms (claimed; verified by the macOS lane of change 008) | Byte-reproducible per platform only |
|------|------|
| documents, manifests, family files, gallery HTML without analysis, target JSON, SVG export; all AGD geometry (arcs, trig, offsets, strokes, booleans, derivations); `inputsHash`, `outputHash`, `sourceHash`, `contentHash`; ZIP framing for identical inputs | PNG and PNG-embedding containers (ICO, ICNS, kit files); kit descriptors and the gallery index (they hold PNG hashes); glyph outlines (pending the owner, D-21); analysis numbers and gallery HTML with analysis |

Staleness, drift and kit checks use only cross-platform source hashes; `--recompute` compares
bytes; kit `exists` never compares rasters; a non-glyph cross-platform difference is a defect. The
libm-free claim covers the D-21 geometry stages; SVG import's trigonometry belongs to change 008.

### Resource limits (Q-03)

| Input | Limits |
|-------|--------|
| Path operands | existing parse budgets; MCP operand file ≤ 1 MiB; point budget and `MaxFitOperations` per command; `clipperStages ≤ 4`; tolerance [0.008, 100] with fail-fast feasibility |
| Geometry magnitude | evaluation-space abs(coord) + extent ≤ 1e9 before the first Clipper call; emitted abs(coord) ≤ 1e9; abs(offset) ≤ 1e6; stroke width (0, 2e6]; miter limit [1, 1000] everywhere; out-of-range source limits refused; point counts checked a priori |
| Derivations | ≤ 1024 per document, ≤ 64 operands, depth ≤ 32, ≤ 2^18 work units |
| Family and axes | ≤ 256 KiB, depth ≤ 16, ≤ 16 masters, 8 axes, 16 values, 256 overrides |
| Placement | cycle check ≤ 8 levels and 64 files; ≤ 4096 groups; one resolution per `(family, variant, master)`; size 1–8192 |
| Manifest v2 | existing 1 MiB, 256 occurrences, 64 MiB, 4096 inventory, 64 Mpx; ≤ 64 targets, 32 sizes, 4 appearances, 16 roots |
| Kit | descriptor ≤ 4 MiB, ≤ 4096 files, walk ≤ 4097 entries and depth 64, no ZIP64, lock 30 s |
| Sheets and gallery | ≤ 64 references with conditions, ≤ 32 conditions, ≤ 256 cells, ≤ 16 sheets, ≤ 64 MiB; index ≤ 1 MiB, depth 8; refresh 1–3600; lock 30 s |
| Analysis | ≤ 8 sizes ≤ 1024 px, ≤ 4 grounds, ≤ 32 regions, ≤ 64 components, ≤ 64 Mpx, ≤ 2^32 counted operations, width clamp `max(4, 2·minStroke)`, thresholds ≤ 16 px |

Every row gets a boundary test at the limit and one over in the slice that introduces it.
Injected budgets are Core test seams only; no CLI or MCP option raises a budget.

### Security controls (normative)

MCP takes structured, confined operands and references with bounded reads and link and
special-file rejection, never `@file`; CLI `@file` is inspected and refused where inspection is
not admitted; the file-reference rule covers every reference; magnitude bounds keep untrusted
document numerics inside the int64 Clipper domain; manifest and kit overlap, name and root rules;
kit staging cleanup only under the lock for marked real directories without following links;
no-replace publication only through the qualified primitives (D-28); `kit verify` inspects before
opening, bounds reads and walks and accepts the producer policy only with a pin; `kit pack` refuses
aliasing, writes portable names, no ZIP64 and hashes while writing; the gallery's closed names,
strict index, lock, hash-checked deletion, temporary-and-rename writes, escaping, no scripts, CSP
and no listener; work budgets with cancellation; no absolute paths in artifacts.

### Parity and discoverability

Every capability is reachable on both surfaces through one Core service; the pipeline gets MCP
tools. `get_capabilities` adds `formats {assetManifest: 2, family: 1, kit: 1}`, `geometry
{algorithm, defaultTolerance, minTolerance, maxClipperStages: 4, sampleSpacing: "T/32",
miterLimit {default 4, min 1, max 1000}}`, `targets [...]` and `analysis {algorithm, checks}`.
Each slice updates `docs/surface-manifest.json`, `docs/CLI_MCP_PARITY.md` and an agent-guide
recipe.

### Verification layers (every slice cites this)

For every new or changed command and tool: Core unit and property tests; CLI JSON shape and exit
code; MCP stdio wire tests per tool (envelope, error flag, confinement); read-only proofs for
`plan`, `check`, `verify`, `inspect` and `analyze` (the source tree is hash-identical after
success, failure and cancellation); the registration inventory and parity table; an installed-tool
smoke for slices with new commands or bundled resources.

### Error and exit codes

Operation errors carry the prefixes `PATH_`, `DERIV_`, `FAMILY_`, `PLACE_`, `ASSET_`, `KIT_` and
`GALLERY_`; numbered findings `DERIV001…`, `FAMILY001…`, `PLACE001`/`002`; analysis
`LEGIBILITY_*`. Exit codes are the existing 0 to 6 plus 7:

| Command | 0 | 2 | 3 | 4 | 5 | 6 | 7 | 1 |
|---------|---|---|---|---|---|---|---|---|
| `path …`, `text outline` | success | — | — | bad arguments | — | — | — | typed error |
| `derive check` | fresh, identical or equivalent | invalid | — | bad arguments | — | stale, stale-upstream, edited, differs | — | I/O error |
| other `derive` | success | — | — | bad arguments | — | — | — | typed error |
| `family check` | clean | error | warning | bad arguments | — | stale or edited | — | I/O error |
| `family place` | success | — | — | bad arguments | — | — | — | `PLACE_*` |
| `assets build/check` | success | strict findings | — | bad arguments | — | drift | — | typed error |
| `kit build` | built or `exists` | strict findings, `KIT_INTEGRITY` | — | bad arguments | — | — | `KIT_VERSION_IMMUTABLE` | `KIT_LOCKED`, typed |
| `kit check` | clean | `KIT_INTEGRITY` | — | bad arguments | — | sources changed, version missing | — | I/O error |
| `kit verify` | verified | integrity, pin mismatch, policy | — | bad arguments, `KIT_PIN_REQUIRED` | — | — | — | I/O error |
| `analyze` | completed | — | — | bad arguments | `--fail-on` matched, or incomplete or unsupported under it | — | — | typed error |
| `gallery write` | written | — | — | bad arguments | — | — | — | `GALLERY_*`, typed |

Bad arguments (4) and typed errors (1) pre-empt findings; among findings 2 > 6 > 3 > 0; each mixed
case has a CLI test.

### Explicitly not built in this target

Live booleans, instances or modifiers (format 2); a certified deviation bound; text derivations and
text operands; variable-width strokes and dash outlining; the `square` offset join and `joined`
end type; SVG `<mask>` knockouts; atlases and sprite or tile metadata (change 014); Android adaptive
icons, Windows tiles and MSIX, icon fonts; pixel-diff images; auto-rebuild; cross-document
derivations; upward references and a root marker; DTCG `tokensFrom`; `kit check --regenerate`; kit
publication off Linux and macOS; the preview server and file watching; kit signing, hosting or a
registry; crash-durable multi-file publication; a managed font reader unless the owner chooses it;
motion and Blender.

## Alternatives

Each area's alternatives are in its decision (D-21 to D-26). Leaving these rules to each slice was
rejected: slices would diverge on severities, limits and exit codes that agents rely on across
commands.

## Revisit when

A slice needs a rule here changed: it returns to architecture review instead of deviating.
